0一句话结论

产品定位

一个「孩子玩、家长懂」的家庭财商练习场。
孩子做真实的金钱决策，犯错只花虚拟币；家长拿到今晚可以照着说的 3 句话。

给孩子 这是我的店，我说了算。赚了是我的，花光了也是我的。有人讲给我听，不用读很多字。
给家长 不用你会教。今天他做了什么选择、是懂了还是蒙的、今晚该聊什么，都给你了。

🎯 抓什么痛

家长不知道怎么教、不知道教得对不对、孩子不听自己的。产品第一服务对象是家长，游戏化是手段不是目的。

🧩 靠什么赢

市面两端空白：内容课没有决策后果，成人交易工具合规红线。中间地带是「自己选、自己承担虚拟后果、家长看得见」。

📐 拿什么验收

北极星＝7 日内完成 ≥3 节的家庭比例。明确否定把「使用时长」当指标——它会直接把设计带向成瘾机制。

1信息架构

👦 孩子端 · 一条主线

  • 章节地图（默认首页，全屏纵向路径）
  • ├ 第一章 · 认识我的钱 免费
       1-1 我的钱有多少？ · 1-2 先买哪一样？ · 1-3 卖到的钱都是赚的吗？
  • └ 第二章 · 经营我的钱 订阅
       2-1 今天准备几份？ · 2-2 给愿望留一点钱 · 2-3 计划变了怎么办？
  • 单节五步：故事 → 小芽示范 → 一起练 → 自己试 → 我的发现
  • 徽章墙 + 拓展模块（思考站 / 零花钱小镇）
  • 任何页面都有「回地图」出口

👨‍👩‍👧 家长端 · 独立视图

  • ① 一句结论：他今天学会了什么
  • ② 今晚可以聊 ×3：先肯定 → 再提问 → 生活延伸
    ← 这是让家长每周回来的理由，核心差异点
  • ③ 他真实做了什么：选择 / 预测 vs 实际 / 用了几次提示
  • ④ 能力地图：已练 ●●● / 未练 ○○○
  • ⑤ 下一步建议：降低决策成本
  • ⑥ 关于安全：不碰真钱、不要隐私、AI 标注、条款

🚪 入口规则（合规相关）

家长中心入口放在地图左下角低视觉权重位置，需一次「家长意图」确认动作防止孩子误入。儿童端永不出现价格、订阅按钮、促销、倒计时。

2核心闭环：这个产品为什么能成立

STEP 1 · 孩子进入一节，12 分钟，做一个真实的金钱决策
→
STEP 2系统给具体反馈：钱变了多少、差了几枚
→
STEP 3拿星星 / 徽章，小芽说「去告诉爸爸妈妈」
→
STEP 4 · 家长点开家长中心，3 分钟读完
→
STEP 5照着「今晚可以聊」和孩子真的聊了一次
→
STEP 6 · 转化家长感到价值 → 愿意续订 / 付费

关键洞察：回路的真正引擎是 STEP 3 → 4 ——孩子必须主动去找家长说。所以「每节结束把孩子推向家长」不是彩蛋，是本产品最重要的跨端接口；露出的徽章必须是孩子会想炫耀的。

3MVP 范围：第一个章节

💡 最高性价比的范围决策

现有代码里已经有 6 节完整课程，只是缺「章节」这一层。建议重组为 2 章 × 3 节，MVP 只做第一章。内容零新增，开发量极小，能最快产出可演示 Demo。

层内容来源
In Scope第一章 3 节 · 节前趣味视频（每节 1 段 60–120 秒） · 角色对话 + 设备语音 · 分步动画 · 虚拟奖励体系 · 家长中心 · 本机存档 · 移动端响应式 · PWA视频口子已落地
新增开发章节层（封面 / 进度 / 完成徽章）· 家长观察记录条目化 · 今晚可以聊 · 能力地图 · 解锁拦截层 · 节前趣味视频M1–M3
本期不做后端 · 账号 · 真实支付 · App 上架 · 社交 · 运营后台 · AI 视频自动生成流水线（成片线下制作 + 手工登记）明确排除

4商业模式分层

免费层 ¥0

第一章 3 节完整可玩 + 全部机制 + 拓展模块基础 + 家长中心。
必须是完整体验，不能是「试吃版」——家长要走通一轮才可能付费。

订阅层 定价待定

第二章及以后全部节次 + 后续更新内容免费 + 家长中心完整能力地图与建议。
免费层的结束点应落在情绪高点：刚拿到章节徽章、正想继续时。

🔓 未解锁拦截 · 儿童端唯一的拦截界面

小芽歪头想了想：「这一段我还没学会呢。要不要去问问爸爸妈妈？」+ [ 回地图 ]

这是转化率最高的位置，也是唯一合规的沟通方式。价格、订阅按钮一律不出现在儿童可访问的任何界面。

5⚠️ 必须拍板的三个决策

决策 1 已拍板（视频进 MVP，技术口子已落地）；现在真正待定的是它的片源方式（Q-01a）。

决策 1（Q-01）· 视频已定：MVP 做，形态是「趣味视频 + 小游戏」

已拍板：每节开头放 1 段 60–120 秒趣味视频做钩子，其后接现有互动练习（= 小游戏）。分工是——视频负责「想看下去」，小游戏负责「真的会做」。只有视频会看完就忘，只有游戏则进门门槛太高，所以视频必须在开头，每节最多 1 段。

技术口子已落地（不再是瓶颈）：新增 video-lessons.js / video.css / media/video/。放片＝拷文件 + 改一行清单，不用改代码；没配片时页面与现在完全一致，可以逐节灰度上线。契约见 docs/VIDEO-MODULE.md。

现在卡排期的是内容侧（新 Q-01a）：片源用 AI 生成、动画外包，还是现有素材剪辑？三者画风、单节成本、交期差一个数量级。建议只定一件事：先做第 1 节的样片，确认画风与成本后再批量。

决策 2（Q-02）·「纯前端」与「会员订阅」在技术上互斥

会议同时决定了两件无法共存的事：①「纯前端实现，暂不涉及后端开发」②「基础免费 + 会员订阅」。

订阅必须依赖 支付通道 + 订单校验 + 权益下发，这三件事在纯前端无法可信完成（可被任意绕过）。

建议：MVP 期不接真实支付——第二章显示为「即将开放」，用兑换码 / 白名单 / 家长意向登记验证真实付费意愿；Phase 2 再接后端 + 支付。
若坚持 MVP 就要真实付费，则「暂不涉及后端」这一决策必须被推翻。

决策 3（Q-03）·「第一个章节」的确切范围

现有代码只有「课」没有「章」。建议采纳：第一章 = 现有前 3 课（数钱 / 需要与想要 / 收支利润），第二章 = 后 3 课。

这样 MVP 内容零新增，只需补章节层。若老板另有划分，请直接指定。

9合规红线（不可谈判）

🚫 已否决

在线真实股票市场功能 —— 存在诱导未成年人投资的违规风险，决定不予采纳（会议决议）。现有虚拟市场实验室须复核确认为纯虚构。

🔒 儿童数据

不收集、不上传、不共享。不要求真实姓名 / 学校 / 地址 / 生日 / 家庭收入。数据仅存本机。AI 生成内容须在家长端标注。

🎮 奖励机制

禁用抽奖、开箱、随机掉宝、连胜惩罚、倒计时、排行榜。多邻国可借鉴的是路径感，不是焦虑驱动。

📌 上线门禁（公开收费前必须完成）

儿童可用性测试并修复理解障碍 · 家长服务条款 / 隐私政策 / 退款说明 · 未成年人个人信息保护合规声明 · 受保护的访问控制 · 支付与订阅权益校验
