# 儿童财商教育产品 · 产品设计文档（Design V1.0）

> 配套文档：`docs/SPEC.md`（需求规格说明书）
> 版本：V1.0（初版，待评审）｜日期：2026-09-22
> 目标用户：8–12 岁儿童（使用者） + 其家长（决策者与共育者）
> 代码基线：`money-quest` 仓库初版原型

---

## 1. 设计目标与原则

### 1.1 我们到底在设计什么

不是设计一门课，也不是设计一个游戏。**是在设计一个"家庭谈话的引子"。**

真实的转化链路是这样的：

```
孩子玩 → 做了一个选择 → 系统把选择翻译成家长看得懂的语言
      → 家长知道今晚该问什么 → 家长和孩子的对话发生了 → 家长感受到价值 → 续订
```

如果只做了前半段（孩子玩得开心），家长没有感知，付费不会发生。
如果只做了后半段（家长看完报告），孩子不愿意玩，数据不会积累。

**两端必须都成立，且各自独立成立。**

### 1.2 六条设计原则

| # | 原则 | 具体含义 | 反面案例 |
| --- | --- | --- | --- |
| P1 | **孩子端零门槛** | 打开即玩。不注册、不填表、不选年级、不看说明页 | "请先创建账号" |
| P2 | **决策权归孩子** | 只提供情境和后果，不预告"正确答案"，不评判偏好 | "你应该先买铅笔" |
| P3 | **错误是免费的** | 任何错误只体现在虚拟结果里，不扣分、不批评、不惩罚 | 红叉 + 错误音效 |
| P4 | **家长端结论优先** | 家长只想知道"孩子怎么样 + 我该说什么"，不想看教学理论 | 大段教育理念 |
| P5 | **时长不是目标** | 一次一节，学完就建议休息。不设计"再来一局"的钩子 | 每日签到 + 断签惩罚 |
| P6 | **安全是产品特性** | "不碰真钱、不要隐私"要在界面上被家长**看见**，而不是藏在隐私政策里 | 只在 footer 放一个链接 |

### 1.3 设计禁忌清单

以下元素**一律禁止**出现在儿童端：

- ❌ 倒计时压力、限时挑战、排行榜、好友 PK
- ❌ 抽奖箱 / 开箱 / 随机掉宝 / 概率性奖励
- ❌ "再来一次就送你 10 颗星"式成瘾诱导
- ❌ 红色错误提示、"错误""失败""你错了"等否定性文案
- ❌ 任何金额与真实货币的视觉混淆（不出现 ¥ / $ / 银行卡 / 钞票据实图形）
- ❌ 任何股票 K 线、红绿涨跌、真实标的名称
- ❌ 面向儿童的付费入口、价格标签、促销文案

## 2. 双用户模型

### 2.1 两个用户，两套语言

| | 孩子端 | 家长端 |
| --- | --- | --- |
| 核心问题 | "我现在要做什么？" | "我的孩子怎么样？" |
| 界面语言 | 口语、短句、第二人称、拟人化 | 结论、数据、可执行建议 |
| 主要交互 | 点、拖、选、滑 | 读、看、展开 |
| 单次时长 | 12–15 分钟 | ≤ 3 分钟 |
| 视觉基调 | 明亮、圆润、角色在场、动效丰富 | 克制、留白、信息密度高、几乎无动效 |
| 入口 | 首页正中，一步到达 | 左下角小入口，不干扰主路径 |
| 文案长度 | 单句 ≤ 20 字，单屏 ≤ 3 句 | 允许段落与列表 |

> **关键约束**：家长端**不是**儿童端的换皮。共用组件（角色、卡片、按钮）可以复用，但排版密度、信息层级、动效策略必须分开设计。

### 2.2 家长的三层心理需求（由浅入深）

```
第 1 层：想知道孩子今天干了什么          → 用「观察记录」满足（低频价值）
第 2 层：想知道该怎么跟孩子说            → 用「今晚可以聊」满足（高频价值 · 核心差异点）
第 3 层：想确认这钱花得值、方向是对的     → 用「能力地图 + 下一步建议」满足（付费理由）
```

**设计含义**：家长中心不能只做"数据看板"，必须做**"话术供给"**。第 2 层才是让家长每周回来的理由。

## 3. 信息架构

```
财商经营岛
│
├── 【孩子端】学习主路径
│   ├── 1. 开场 · 小芽欢迎（首次）
│   │      └── 起个昵称（可选，仅存本机，可跳过）
│   │
│   ├── 2. 章节地图（默认首页）
│   │      ├── 第一章 · 认识我的钱  ★免费
│   │      │     ├── 1-1 我的钱有多少？
│   │      │     ├── 1-2 先买哪一样？
│   │      │     └── 1-3 卖到的钱都是赚的吗？
│   │      │           └── 🏅 章节完成 → 发徽章 + 解锁第二章
│   │      └── 第二章 · 经营我的钱  🔒订阅
│   │            ├── 2-1 今天准备几份？
│   │            ├── 2-2 给愿望留一点钱
│   │            └── 2-3 计划变了怎么办？
│   │
│   ├── 3. 单节课程（五步结构）
│   │      ├── ① 故事 → ② 小芽示范 → ③ 一起练 → ④ 自己试 → ⑤ 我的发现
│   │      └── （每步均为：角色对话 + 可选语音 + 分步动画 + 交互）
│   │
│   ├── 4. 徽章墙
│   │      └── 已获得的能力徽章 + 未解锁的灰色剪影（含能力说明）
│   │
│   └── 5. 拓展模块（不占章节进度）
│          ├── 小芽思考站（元认知：计划 / 预测 / 复盘）
│          └── 零花钱小镇（家庭延伸：存 / 花 / 捐 + 家长录入实物清单）
│
└── 【家长端】家长中心（独立视图，深色低调入口）
       ├── A. 本节观察记录（按节聚合）
       ├── B. 今晚可以聊（3 条话术）★核心差异点
       ├── C── 能力地图（孩子练过哪些能力、哪些还没练）
       ├── D. 下一步建议（下一节 / 生活延伸活动）
       ├── E. 使用控制（每日节数上限 / 休息提醒）
       └── F. 关于安全（隐私、数据存储、AI 声明、服务条款、退款说明）
```

### 3.1 导航原则

- **孩子端永远只有一条主线**：地图 → 节 → 地图。任何页面都有明确的"回地图"出口。
- **家长端不打断孩子端**：家长中心只能从地图页左下角的低视觉权重入口进入（需要一次"家长意图"确认动作，如长按 2 秒或答一个简单算术题，防止孩子误入）。
- **不出现多级 Tab 栏**：8–12 岁用户对底部 Tab 的理解成本高于收益，且会稀释"一条主线"的心智。

> **现状问题**：当前 `money-lab.html` 没有直达地图的返回入口，需两跳才能回首页。M1 必须补齐统一返回。

## 4. 核心用户旅程

### 4.1 首次体验（目标：8 分钟内让孩子完成首节 + 家长看到第一条记录）

| 步骤 | 孩子看到 | 系统行为 | 设计要点 |
| --- | --- | --- | --- |
| 1 | 小芽挥手："嗨，我是小芽！你叫什么？" | 展示昵称输入（**可跳过**） | 不做注册、不做邮箱、不做年级 |
| 2 | 地图：第一章的第 1 节在发光，其他是灰色 | 突出唯一推荐起点 | **只亮一个**，避免选择困难 |
| 3 | 1-1 故事：小芽去野餐，口袋里有 10 枚星币 | 角色对话 + 可选语音 + 星币动画 | 首句必须 3 秒内出现 |
| 4 | 小芽示范："我先数一数……1、2、3……" | 分步动画，每步可暂停/重播 | 让孩子看见钱被付出 |
| 5 | 一起练："你想买什么？" | 点选，实时显示余额 | 允许超预算，不拦 |
| 6 | 自己试：换个情境再来一次 | 隐藏总价，先预测 | 检验是否迁移 |
| 7 | 我的发现 + 家庭小活动 | 发星星 + 徽章 + 提示"去跟爸爸妈妈说说看" | **主动把孩子引向家长** |
| 8 | （家长打开家长中心） | 生成观察记录 + 3 条话术 | 家长 3 分钟内可读完 |

### 4.2 习惯回路（目标：家庭每周活跃 ≥ 3 天）

```
        ┌─────────────────────────────────────────┐
        │  提示：孩子自己想起 / 家长提醒            │
        ↓                                          │
   打开 → 地图上有"下一步"在发光                     │
        ↓                                          │
   一节 12 分钟 → 星星 +1、进度条前进                 │
        ↓                                          │
   孩子："妈妈你看我拿到徽章了！"                      │
        ↓                                          │
   家长打开家长中心 → 看到"今晚可以聊"→ 当晚发生对话    │
        ↓                                          │
   家长价值感获得满足 ────────────────────────────────┘
```

**这个回路的真正引擎是最后两步。** 如果孩子不主动找家长说，回路就断了。因此：

> **设计决策**：每节结束时，小芽有一句固定台词把孩子推向家长——"去把今天发现的事告诉爸爸妈妈吧"。并且在结束时露出的徽章是**孩子会想炫耀的东西**（有名字、有图形、有颜色）。这是本产品最重要的一个"跨端接口"。

> **不做的事**：不做推送通知、不做"连续学习 N 天"的断签惩罚。习惯靠内容和家长的主动使用来养成，不靠焦虑。可选的正面"连续学习"展示（如"这周你来了 3 次"）属于 P2。

### 4.3 家长旅程（目标：每周打开 ≥ 2 次，单次 ≤ 3 分钟）

| 步骤 | 家长看到 | 设计要点 |
| --- | --- | --- |
| 1 | 地图左下角「家长中心」小入口 | 视觉权重低，但不难找 |
| 2 | 顶部一句话结论："今天他学会了先看自己有多少钱，再决定买什么" | **先给结论**，不给数据 |
| 3 | 「今晚可以聊」三张卡：一句肯定 + 一个问题 + 一个生活延伸 | **可直接照读**，不需要理解 |
| 4 | 往下才是：本节做了什么选择 / 预测 vs 实际 / 用了提示几次 | 数据放后面，供想深究的家长 |
| 5 | 能力地图：已练 / 未练 | 给出"方向感" |
| 6 | 下一步建议：明天试试 1-2 / 或周末去超市时让他自己算 | **降低决策成本** |

## 5. 章节内容设计

### 5.1 章节结构（新增层）

现有代码只有"课"，**没有"章"**。M1 需要新增章节层：

```
章节 Chapter
├── 封面：章节名 + 一句话目标 + 3 节缩略 + 完成度环
├── 节 Lesson × 3
├── 章节完成态：发章节徽章 + 一句"你现在会……"的能力总结
└── 解锁下一章（或对未订阅用户展示"去问问爸爸妈妈"）
```

### 5.2 单节内容结构（沿用现有五步，保持不变）

现状代码已是这个结构，**无需重构**，只需在节外包一层章节：

| 步骤 | 孩子的动作 | 系统的供给 | 留下的记录 |
| --- | --- | --- | --- |
| ① 故事 | 听 / 读一个情境 | 角色对话、情境插画、初始金额 | — |
| ② 小芽示范 | 看小芽做一遍 | 分步动画（钱币流出流入、库存变化）、可选语音 | — |
| ③ 一起练 | 在引导下做一次 | 实时提示、逐项反馈 | 第一次作答 |
| ④ 自己试 | 换情境独立做一次 | 仅在被请求时提示 | 是否用提示、是否改方案 |
| ⑤ 我的发现 | 选一句总结、看家庭活动 | 结论卡 + 生活延伸任务 | 理由选择 |

### 5.3 第一章内容规格

| 节 | 情境 | 核心问题 | 能力 | 徽章 |
| --- | --- | --- | --- | --- |
| 1-1 | 野餐 / 买画画用品 | 我有多少钱？买完还剩多少？ | 数钱、购买、余额 | 🪙 **会数钱** |
| 1-2 | 开店工具 / 雨天出门 | 哪些是需要的，哪些是想要的？ | 区分 need / want | 🎯 **分得清** |
| 1-3 | 奶茶店 | 收到的钱都是赚的吗？ | 收入 / 支出 / 利润 | 📈 **看得懂利润** |

> **1-3 的措辞注意**：这是本产品距离"投资"最近的一节。必须严格限定在**经营语境**（进货成本、售价、毛利），且界面**禁止**出现 K 线、涨跌箭头、股票名称。利润的图形表达建议用"一摞硬币分成两堆"，而非曲线图。

### 5.4 内容模型（沿用现有 schema，扩展字段）

```
Lesson {
  id, icon,
  title: { zh, en },
  goal,                                 // 一句话教学目标（家长可见）
  skillTag,                             // 对应能力标签，用于能力地图
  badge: { id, name:{zh,en}, icon },     // 本节徽章
  story:  [ turn... ],                   // 角色对话
  demo:   [ { amount, title, text } ],   // 分步动画帧
  practice: Practice,                    // 一起练
  challenge: Practice,                   // 自己试（迁移）
  takeaway,                              // 结论卡
  home,                                  // 家庭小活动
  parent: {                              // 【新增】家长中心内容
    summary,                             // 一句结论
    talk: [ 肯定句, 提问句, 生活延伸 ],    // 今晚可以聊 ×3
    watchFor                            // 观察要点
  }
}
```

**已有题型（无需新增）**：`choice`（单选 + 逐项反馈）、`basket` / `shopBasket`（预算 + 必需项）、`stock`（备货份数）、`jars`（滑杆分配）。

> **设计建议**：MVP 期**不新增题型**。四种题型已能覆盖第一章全部教学目标，新增题型的边际价值低于把家长中心做好的价值。

## 6. 页面与交互规格

### 6.1 章节地图（默认首页）

| 元素 | 规格 |
| --- | --- |
| 布局 | 单列纵向路径；移动端一屏可见 1.5 个章节 |
| 章节卡 | 章节名 + 一句话目标 + 完成度环（3 段）+ 3 个节的圆点 |
| 节的节点 | 三个状态：**可玩**（实色 + 微微呼吸动效）/ **已完成**（打勾 + 星星数）/ **锁定**（灰色 + 锁图标） |
| 推荐指引 | 下一个可玩的节持续轻微脉冲，**同一时刻只有一个** |
| 底部 | 拓展模块入口（思考站 / 小镇）+ 左下角家长中心入口 |
| 未订阅章节 | 界面**对孩子**显示为"还要继续吗？去问问爸爸妈妈"，不显示价格 |

### 6.2 单节课程页

沿用现有 `dialogue.css` 的角色对话布局。核心要素：

| 元素 | 规格 |
| --- | --- |
| 角色舞台 | 小芽 / 团团，四表情（欢迎 / 好奇 / 开心 / 安慰），轻微摆动（遵守减少动效） |
| 对话气泡 | 一次只显示一小段，不逐字打字、不强制等待；可点"接着聊"或开启连续朗读 |
| 朗读栏 | 播放/暂停 / 语速 / 重播 / 静音；默认 0.95× |
| 演示动画 | 真实对应数量的星币图形，逐枚入出；可手动切帧、播放、暂停、重播 |
| 练习区 | 实时余额显示；提交后逐项反馈（不是统一对错） |
| 提示 | 被动可点；**新增**：连续两次答错时主动给出更具体的脚手架（FR-L11） |
| 出口 | 始终可见的"回地图" |

**交互硬约束**：

- 语音**不自动答题、不自动跳步**——所有推进必须由孩子点击。
- 答对反馈 = 具体解释 + 短提示音 + 一颗星星；**不做**文字"正确！"的通用弹窗。
- 答错反馈 = 放轻声音 + "我们一起看看" + 重述数字；**不做**红叉、不做错误音效。

### 6.3 徽章墙

| 元素 | 规格 |
| --- | --- |
| 已获得徽章 | 彩色 + 徽章名 + **一句话能力说明**（家长看得懂） |
| 未获得徽章 | 灰色剪影 + 同样显示能力说明（让孩子知道可以练什么） |
| 章节完成徽章 | 更大尺寸，独立一行 |
| 无"收集进度百分比"压力 | 不显示"3/12 已收集"，避免收集焦虑 |

### 6.4 家长中心

**这是本产品最需要重新设计的部分。** 现有家长中心偏"说明文档"，需要升级为"决策工具"。

```
┌────────────────────────────────────────────┐
│  家长中心                          [ 关闭 ] │
├────────────────────────────────────────────┤
│  ✅ 他今天学会了                              │
│     「先看自己有多少钱，再决定买什么」          │  ← 一句结论，最大字号
├────────────────────────────────────────────┤
│  💬 今晚可以聊                                │
│  ┌──────────────────────────────────────┐  │
│  │ ① 先肯定：                            │  │
│  │   "你先数了数口袋里有多少钱，        │  │  ← 可直接照读
│  │    这个办法真好。"                    │  │
│  └──────────────────────────────────────┘  │
│  ┌──────────────────────────────────────┐  │
│  │ ② 再提问：                            │  │
│  │   "如果你是老板，进货的钱算不算       │  │
│  │    赚到的钱？"                        │  │
│  └──────────────────────────────────────┘  │
│  ┌──────────────────────────────────────┘  │
│  │ ③ 生活延伸：                          │  │
│  │   "周末去超市，让他自己算一次总价。"   │  │
│  └──────────────────────────────────────┘  │
├────────────────────────────────────────────┤
│  📊 他真实做了什么（可展开）                   │
│     · 选择：先买了面包和果汁                  │
```

**家长中心三条铁律**：

1. **不给分数**。不出现"财商分 82""超过 70% 的同龄人"。
2. **不评价人格**。不出现"他很聪明""他不够耐心"。
3. **不制造焦虑**。不出现"您的孩子已经落后"。空状态也要是"怎样开始"，不是"还没有任何数据"。

## 7. 进度与奖励体系

### 7.1 三类数值，严格隔离

| 数值 | 用途 | 可否消费 | 可见位置 |
| --- | --- | --- | --- |
| **经验 XP** | 解锁与等级 | 否 | 地图顶部进度条 |
| **学习星星 ⭐** | 记录"练过几次" | **否**（明确不可花） | 节节点、徽章墙 |
| **练习钱袋** | 只在该练习内有效 | 是（教学用） | 练习区内，**不出练习区** |

> **关键设计**：三个数值的视觉必须完全不同（颜色 + 图形 + 位置），避免孩子理解为"可以攒起来买东西"。星币是教学道具，星星是行为记录，经验是进度——三者混用会直接破坏教学语义。

### 7.2 发放规则

| 事件 | 发放 | 备注 |
| --- | --- | --- |
| 首次通过一道练习 | +1 ⭐，短提示音 | 固定值，无随机 |
| 复习已通过的题 | 可以再得 ⭐ | 鼓励复习 |
| 刷新 / 重复点击 | **不**再发放 | 已实现 |
| 完成一节 | +经验，发本节徽章 | |
| 完成一章 | 发章节徽章 + 解锁下一章 | M1 新增 |
| 答错 | **不扣任何东西** | |
| 中途退出 | 保留进度，不清零 | |

### 7.3 明确不做的机制

连胜 streak / 断签惩罚 / 每日签到奖励 / 排行榜 / 好友对比 / 限时活动 / 抽奖 / 开箱 / 概率掉落。

> **与"多邻国模式"的关系**：会议提出参考多邻国。**可借鉴的是**：清晰的学习路径、可见的进度、每天一点点的节奏、游戏化反馈的密度。**不可借鉴的是**：streak 断签惩罚、红心生命值消耗、排行榜。原因：多邻国的激励模型建立在"焦虑驱动 + 损失厌恶"上，这与儿童教育产品的合规边界和家庭教育场景直接冲突。

## 9. 会员与解锁设计

### 9.1 分层

| 层 | 内容 | 价格 |
| --- | --- | --- |
| **免费** | 第一章 3 节完整可玩 + 拓展模块基础部分 + 家长中心（第一章记录） | ¥0 |
| **订阅** | 第二章及以后全部节次 + 后续更新内容免费 + 家长中心完整能力地图与建议 | 待定（Q-06） |

### 9.2 体验原则

- 免费层必须是**完整体验**（3 节 + 全部机制 + 家长中心），不能是"试吃版"。家长需要完整走通一轮才可能付费。
- 免费层的结束点应落在**情绪高点**：孩子刚拿到章节徽章、正想继续时，出现"去问问爸爸妈妈"。这是转化率最高的位置，也是唯一合规的沟通方式。

### 9.3 解锁流程（MVP 两阶段方案）

**MVP 期（无后端）——只验证付费意愿，不收款：**

```
孩子完成第一章 → 看到"去问问爸爸妈妈"
                        ↓
家长打开家长中心 → 看到 "第二章已开放，先看看有哪些内容"
                        ↓
                 [ 查看第二章内容 ]  → 展示 3 节标题与教学目标
                        ↓
                 [ 我愿意订阅（登记意向） ]  → 收集手机号/邮箱 + 期望价格区间
                        ↓
                 提示："感谢！上线时第一时间通知你，首批订阅有优惠"
```

**Phase 2（有后端）——真实支付：**

订阅页（家长端）→ 支付（微信/支付宝/Stripe，按出海地区定）→ 订单校验 → 权益下发 → 解锁第二章。

### 9.4 合规红线

- 儿童端**永不**出现价格、订阅按钮、促销、限时、倒计时
- 不做自动续费的"默认勾选"
- 退款说明必须在订阅页首屏可见
- 不针对儿童做任何付费引导文案

## 10. 语音与动效规范

### 10.1 语音

沿用现有 `teaching-media.js` 实现（浏览器 Web Speech + Web Audio），不新增付费配音 API。

| 项 | 规范 |
| --- | --- |
| 默认语速 | 0.95× |
| 可选语速 | 更慢（0.8×）/ 普通（1.0×） |
| 停顿 | 疑问句后 650ms（给思考时间），普通句 260ms |
| 音高 | 疑问句 1.07；团团额外 +0.05（区分角色） |
| 数字朗读 | 数学符号转口语（`−` → "减"），金额与正负关系**不可改写** |
| 看门狗 | 7 秒无发声则继续下一句，防止卡死 |
| 降级 | 无中文语音 → 保留完整文字与无声演示，**不阻断** |
| 家长端标注 | 明确写明"AI 生成配音" |

**角色声音人设**（详见 `VOICE_BRIEF.md`）：温柔、亲切、带笑意的年轻成年学习伙伴；**不**模仿真人、**不**克隆儿童声音、**不**尖细变声或装婴儿。

**情绪规则要点**：答对时肯定**方法**（"你先看了自己有多少钱，这个办法真好"），而不是夸"聪明"；答错时放轻声音、不失望、不责备。

### 10.2 动效

| 场景 | 规范 |
| --- | --- |
| 星币流入流出 | 真实对应数量，逐枚 35ms 延迟，整体 620ms |
| 逐帧自动播放 | 每帧 3200ms（足够孩子看清） |
| 角色待机 | 轻微摆动，幅度小 |
| 减少动效 | 遵循系统 `prefers-reduced-motion` **优先**；页面设置次之 |
| 转场 | ≤ 240ms，缓出 |
| 禁止 | 闪烁、抖动、突然放大、连续循环的吸引注意力动效 |

## 12. 儿童可用性设计规范（A11y & 儿童友好）

| 项 | 规范 |
| --- | --- |
| 对比度 | 正文 ≥ 4.5:1，大字号 ≥ 3:1（WCAG 2.1 AA） |
| 文本缩放 | 支持至 200% 不破版 |
| 阅读难度 | 单句 ≤ 20 字；避免成语、被动句、双重否定 |
| 识字支持 | 关键操作**必须**有图形或图标，不能只靠文字 |
| 语音辅助 | 所有教学内容均可听；语音不是唯一通路 |

| 无时间压力 | 无倒计时、无超时退出、无自动跳步 |
| 中断恢复 | 任何中断后回到原步骤，进度不清零 |
