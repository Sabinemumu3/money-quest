## 1. 视频解决什么问题（先说清楚，免得做成装饰）

「趣味视频 + 小游戏」不是两种内容形式相加，而是**分工**：

| | 趣味视频 | 小游戏（现有互动练习） |
| --- | --- | --- |
| 负责 | **想看下去**：给动机、给画面、给心智模型 | **真的会做**：给决策、给后果、给反馈 |
| 回答 | 「为什么要管钱？」 | 「这 4 枚，我买哪个？」 |
| 时长 | 60–120 秒 | 3–6 分钟 |
| 判断成败 | 有没有看到最后（不建议作为 KPI） | 有没有做出选择、改没改方案 |
| 缺了它会怎样 | 进门门槛高，孩子不知道为什么要玩 | 看完就忘，家长无法判断「会没会」 |

**结论**：视频只能放在**每节开头**。放在结尾就变成「奖励动画」，对动机没有帮助；夹在题目中间会打断作答节奏，直接伤害小游戏。

**因此本版的上线单位是「一节 = 1 段片 + 5 步练习」**，一节**最多 1 段片**。

## 3. 接口契约（口子本体）

### 3.1 三层解耦

```
课程数据 lessons.js   →   清单 media/video/manifest.json   →   播放器 video-lessons.js
（不知道有视频）           （运营唯一要动的地方）                （不知道内容是什么）
```

**设计目标**：放一段片 = 拷文件 + 改一行清单。**不需要改课程数据，不需要改渲染逻辑，不需要改版本号。**

### 3.2 课程侧：课程数据不需要声明视频

`lessons.js` 里的课程对象**不加任何视频字段**。渲染时统一问一句「这一步有没有片」：

```js
// lessons.js · stageContent()
if (p.step === 0) {
  const slot = videoSlot(p);                    // 有片返回挂载点，没片返回 ""
  return `${slot}${button(slot ? "接着看故事 →" : "一起看看 →", "next")}`;
}
```

- 没配片 → `slot` 为空串，DOM 与文案**与现在完全一致**（零回归）
- 配了片 → 多一张视频卡，主按钮文案自动从「一起看看 →」变成「**接着看故事 →**」

### 3.3 资产侧：`media/video/manifest.json`

运营唯一的操作面。完整字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `src` | ✅ | 视频路径。**没有 `src` 等于没配片** |
| `webm` | — | 填了优先播 WebM，不支持时自动回退到 `src` |
| `poster` | 建议 | 封面图，1280×720。**首帧不要压字幕、不要压 logo** |
| `captions` | 建议 | `{ "zh": "...vtt", "en": "...vtt" }` |
| `transcript` | **建议必填** | 文字版。字幕缺失或设备无中文语音时，这是无障碍兜底 |
| `duration` | — | 秒。只用于显示「大约 1 分钟」，**不参与任何统计** |
| `title` / `summary` | — | 卡片文案，支持字符串或 `{ zh, en }` |
| `aiGenerated` | AI 生成时 ✅ | 数据标记必须如实置 `true`。**封面不再显示角标**（20260922 起披露位置收进「看文字版」折叠区的完整说明，见 §3.8） |
| `status` | — | `ready`（默认）｜`planned`（先占位、暂不播，等成片） |

### 3.4 播放器 API：`window.MoneyVideo`

| API | 用途 | 返回 |
| --- | --- | --- |
| `slot(lessonId, step)` | 渲染层同步询问「这里要不要留位置」 | 挂载点 HTML 字符串 或 `""` |
| `mount(root, config)` | 把视频卡挂到挂载点上 | 播放控制对象 或 `null` |
| `dispose()` | 离开课程 / 重渲染时释放（存进度、停播、移除节点） | — |
| `pause()` | 「暂停休息」时停画面，**保留卡片与续播位置** | — |
| `has(lessonId, step)` | 同步判断有没有片 | boolean |
| `resolve(lessonId, step)` | 取生效的条目（含评审占位） | 条目对象 或 `null` |
| `preload()` / `manifest()` | 预取 / 读取清单 | Promise / 清单对象 |

**调用约定**：`slot()` 必须在 `render()` 拼 HTML 时调用；`mount()` 必须在节点插入 DOM **之后**调用。`dispose()` 在每次重渲染与关闭课程时调用（已接入 `lessons.js` 与 `app.js`）。

### 3.5 DOM 契约（供设计走查与自动化验收）

| 选择器 | 含义 |
| --- | --- |
| `.lesson-video` | 整张视频卡 |
| `[data-video-lesson]` / `[data-video-stage]` | 这卡属于哪节课的哪个挂载位 |
| `[data-video-state]` | `idle` ｜ `playing` ｜ `paused` ｜ `ended` ｜ `skipped` ｜ `error` ｜ `preview` |
| `[data-ai-generated="true"]` | AI 生成内容，家长中心据此标注 |
| `[data-video-action="play"｜"skip"｜"replay"｜"captions"｜"muted"]` | 全部可交互控件 |

**自动化验收可以直接断言这些属性**，不依赖视觉。

### 3.6 降级链（关键：任何一层坏掉，孩子都能继续）

| 层 | 出问题的情形 | 系统表现 | 孩子能不能继续 |
| --- | --- | --- | --- |
| 1 | 没有清单 / 清单 404 / 离线 | **不渲染视频卡**，页面与配片前一致 | ✅ 完全无感 |
| 2 | 清单里有条目，但文件坏了 / 编解码不支持 | 卡片显示「这段片子这次没能播放。文字版和后面的练习都还在」，**自动展开文字版** | ✅ 按钮照常 |
| 3 | 8 秒没起播 | 同上，判为加载失败 | ✅ |
| 4 | 自动播放被策略拦截 | **本模块从不自动播放**，不存在这一层 | ✅ |
| 5 | 已记录为坏片 | 该课节后续不再尝试（存 `broken`），不反复卡孩子 | ✅ |

> **硬规则**：视频**永不**阻塞推进。不看、不看全、看完，三种情况下「接着看故事 →」都一样可点。**不倒计时、不因为没看完而收回任何东西。**

### 3.7 存储

| 项 | 值 |
| --- | --- |
| 新命名空间 | `future-money-quest-video-v1`（**新开 key，不污染既有 4 个存档**） |
| 版本 | `version: 1`，版本不符即重置（与项目既有约定一致，无迁移逻辑） |
| `watched` | `{ "lesson-1:hook": true }` —— **只有布尔值** |
| `positions` | 续播点秒数，用于「上次看到这里，接着看就行」 |
| `broken` | 坏片黑名单，避免反复重试 |
| `muted` / `captions` | 静音、字幕开关，尊重孩子上次的选择 |

### 3.8 合规：AI 生成必须标注

- `aiGenerated: true` → 数据标记必须如实登记；**披露位置在「看文字版」折叠区内**（完整说明「本片由 AI 生成，内容经人工审核后发布」）
- **20260922 调整**：封面上不再显示「AI 生成 · 已人工审核」角标 —— 封面是给孩子的画面，不该盖审批章；披露仍然存在于卡片内，只是不挡在首屏
- 对应 `SPEC.md` FR-C06：系统须明确标注其 AI 生成属性 —— 折叠区内的说明即该标注的落点
- **流程约束**：AI 生成的片子必须**人工审核后**才能登记 `aiGenerated: true` 上线；未审核的不得置 `true`

### 3.9 埋点口径（守住「时长不是 KPI」）

| 可以记 | 不可以记 |
| --- | --- |
| 看过 / 跳过（布尔） | **观看时长、完播率、播放次数** |
| 是否播放失败（用于质量修复） | 第几秒流失（会被反向优化成「加长钩子」） |
| — | 视频完成后自动推进（会变成看片任务） |

理由：一旦记录时长，团队就会开始优化时长，产品就会从「教孩子做决定」滑向「让孩子多待一会」。**这是本产品的立场问题，不是技术问题。**

## 4. 页面设计 · P-04V 节前视频卡

**目的**：用 60–120 秒把孩子拉进本节情境，然后**主动**进入故事。

### 布局

```
┌──────────────────────────────────────┐
│ ┌──────────────────────────────────┐ │
│ │                                  │ │
│ │        [ ▶ ]  先看一小段，再动手     │ │  ← 16:9 画面区
│ │     看完就可以自己试一试。            │ │
│ │        [ 看视频 ]   约 1 分钟        │ │
│ └──────────────────────────────────┘ │
│  [ 先不看，直接开始 → ]                 │  ← 出口，始终可见
│  ▸ 看文字版                           │  ← 无障碍兜底
└──────────────────────────────────────┘
        ↓ 下方是原有内容
  [ 接着看故事 → ]   ← 有片时文案自动变化
```

### 元素规格

| 元素 | 规格 |
| --- | --- |
| 卡片 | 白底，描边 `--line` 2px，圆角 `--radius-lg`，内边距 12px（≥640px 时 16px） |
| 画面区 | **16:9 固定比例**，圆角 `--radius-md`，底色 `--deep`（影院黑边），`object-fit: contain` |
| 封面层 | 深色半透明 + 顶部淡绿光晕；居中：52px 圆标 + 标题 + 一句话 + 主按钮 |
| 标题 | 19px / 800（≥640px 时 21px），**最多 26 字** |
| 说明 | 14px，不透明度 .88，**最多 34 字** |
| 主按钮「看视频」 | 高 **56px**，胶囊形，`--lime` 底 + `--ink` 字，18px / 800 |
| 时长提示 | 13px，「约 1 分钟」——**不显示精确秒数，不显示进度百分比** |
| 出口「先不看，直接开始 →」 | 高 **52px**，描边次要按钮，**与主按钮同级可见，不做次级弱化** |
| 角标 | 12px 胶囊，仅评审占位用 `--purple` 底（AI 生成的披露在「文字版」折叠区，见 §3.8） |
| 状态提示条 | 13px，`--muted`，位于画面底部，**空文本时不占位** |
| 文字版 | 折叠区，摘要行高 44px |

### 状态机

| 状态 | 触发 | 画面 | 可用控件 |
| --- | --- | --- | --- |
| `idle` | 有片待播 | 封面层可见 | 看视频 / 先不看 |
| `playing` | 点了看视频 | 原生播放条可暂停、可拖动 | 先不看 → 变「跳过后可再看一遍」 |
| `paused` | 暂停 / 切后台 | 停在当前帧 | 同上 |
| `ended` | 自然播完 | 显示「看完啦。现在轮到你试一试。」 | 再看一遍，**不自动推进** |
| `skipped` | 点了跳过 | 收起画面，保留「再看一遍」 | 接着看故事 |
| `error` | 加载/解码失败 | 提示 + 自动展开文字版 | 再看一遍 / 接着看故事 |
| `preview` | 仅 `?videoPreview=1` | 虚线框 + 紫色占位角标 | 仅评审可见 |

### 硬约束

- ✅ **永不自动播放**（浏览器策略与儿童可用性一致要求）
- ✅ **永不自动跳步**：播完必须孩子自己点
- ✅ **永不倒计时**、不显示「还剩 X 秒」，不显示缓冲百分比
- ✅ 跳过**不丢任何东西**：经验、星星、徽章一律照发
- ✅ 首屏必须有出口：`先不看，直接开始 →` 与主按钮同级
- ✅ 无中文语音 / 静音 / 减少动效 → 流程不中断
- ❌ 禁止红色错误态，一律 `--coral` / `--muted`

## 5. 视频制作规格

### 内容规格

| 项 | 要求 |
| --- | --- |
| 时长 | **60–120 秒**。硬上限 150 秒 |
| 结构 | 前 3 秒给冲突（「10 枚够买什么？」）→ 中段给画面化过程 → 结尾**抛出问题**，不直接给答案 |
| 结尾 | 必须把问题交给孩子，衔接第 3 步练习。**片子里不给答案**，答案留在小游戏里 |
| 角色 | 只用小芽 / 团团，形象与 `sunny-expressions.png` 一致 |
| 货币 | 一律「星币」，与练习一致。**不出现真实货币、真实商品、真实价格** |
| 语言 | 语速 ≤ 每秒 5 字；关键词重复一次；数字必须画面上可见 |
| 禁忌 | 无倒计时、无排行榜、无抽奖、无「快来人买」式促销话术、无商业广告植入 |
| 结尾画面 | 定格一个可读的**问题句**，停留 ≥2 秒（有字幕才能读得完） |

### 技术规格

| 项 | 要求 |
| --- | --- |
| 画面 | 横屏 **16:9**，1920×1080 或 1280×720 |
| 编码 | H.264 + AAC 的 `mp4`（必须）；可选 VP9/AV1 的 `webm` 作为首选源 |
| 码率 | 目标 ≤ 2.5 Mbps（1 分钟约 18 MB，2 分钟约 36 MB） |
| 首帧 | **不带字幕、不带 logo**，与 `poster` 视觉连续 |
| 字幕 | WebVTT，单行 ≤ 18 字，最多 2 行，底部留 10% 安全区 |
| 响度 | −16 LUFS 左右；**不是给孩子直接戴耳机的响度**，留出设备音量余量 |
| 静音可懂 | 关掉声音必须仍能看懂（关键信息用画面 + 字幕承载） |
| 文件命名 | `lesson-<节号>-<挂载位>.mp4`，例：`lesson-1-hook.mp4` |

## 7. 离线与体积策略（PWA）

| 项 | 策略 |
| --- | --- |
| 是否预缓存视频 | ❌ **不预缓存**。视频体积会撑爆首次安装 |
| 首次播放 | 需联网。播放后由 Service Worker 运行时缓存，之后离线可看 |
| 降级 | 无网络 + 未缓存 → 走 §3.6 第 2 层，文字版兜底，**流程不中断** |
| Service Worker 修正 | 原实现对**任何**失败请求都回退 `index.html`，会把 HTML 当视频喂给 `<video>`。**已修正**：只有页面导航才回退首页，视频等资源如实失败 |
| 缓存清单 | `CORE_FILES` 已加入 `video-lessons.js` / `video.css`，缓存名已更新 |
| 体积预算 | 第一章 3 节 × ≤36 MB ≈ **≤108 MB**。若超出，改为按节懒加载 + 只缓存最近 2 节 |
