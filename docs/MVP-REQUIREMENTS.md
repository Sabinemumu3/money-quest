# 第一部分 · 风格确定

## 1.1 品牌基调

**对孩子**：温暖 · 轻快 · 我说了算
**对家长**：克制 · 清楚 · 可信

一句话概括：**像一个耐心的大哥哥在陪孩子玩，而不是一个老师在考孩子。**

## 1.2 视觉关键词（是 / 不是）

| ✅ 是 | ❌ 不是 |
| --- | --- |
| 圆润、手绘感、有生命 | 尖锐、硬几何、冷峻科技感 |
| 明亮但不刺眼 | 高饱和荧光色、渐变紫粉 |
| 留白充足、呼吸感 | 信息密集、卡片套卡片 |
| 角色在场，有人味 | 纯 UI、无人称的说明文案 |
| 有童趣但有分寸 | 幼稚化（奶瓶、气球、彩虹、卡通字体） |
| 一点"经营的认真感" | 金融/商务的严肃感（无西装、无西装领带、无 K 线） |

### 配色禁忌（硬约束）

- ❌ 纯红 `#FF0000`、正红 `#E4393C` —— **儿童端禁止出现红色错误态**，错误提示一律用 `--coral` 或 `--muted`
- ❌ 涨绿跌红 / 涨红跌绿 的**任何**金融色彩语义
- ❌ 荧光色、渐变紫粉、霓虹色
- ❌ 状态只靠颜色区分 —— **必须同时有图标或形状差异**（可访问性要求）

## 1.4 字体与排版

### 字体栈

```css
/* 儿童端：圆体优先 */
--font-kid: ui-rounded, "Avenir Next", "Nunito Sans",
            "PingFang SC", "Microsoft YaHei", sans-serif;

/* 家长端：常规无衬线，信息密度优先 */
--font-parent: "Avenir Next", "Nunito Sans", -apple-system,
               "PingFang SC", "Microsoft YaHei", sans-serif;

/* 金额与数字：必须等宽对齐 */
--font-num: inherit;  /* 配合 font-variant-numeric: tabular-nums */
```

> **必须遵守**：任何显示金额、枚数、分数的位置，一律加 `font-variant-numeric: tabular-nums;`。数字跳动会导致孩子数错。

### 字号阶梯

**儿童端**（基准 390px 宽）

| Token | 字号 / 行高 | 用途 |
| --- | --- | --- |
| `--kid-display` | 32 / 1.25 | 章节大标题、完成页主标题 |
| `--kid-title` | 26 / 1.30 | 节标题、页面标题 |
| `--kid-lead` | 22 / 1.45 | 角色对话气泡、引导语 |
| `--kid-body` | 18 / 1.60 | 正文、选项文字、按钮 |
| `--kid-label` | 16 / 1.50 | 标签、徽章名、辅助信息 |

**硬规则**：儿童端正文字号 **不得小于 16px**；教学内容正文不低于 18px。**任何情况下不缩字号来塞内容**，宁可换行或分屏。

**家长端**

| Token | 字号 / 行高 | 用途 |
| --- | --- | --- |
| `--parent-lead` | 21 / 1.50 | **结论句**（全页最大，最重要） |
| `--parent-h1` | 24 / 1.35 | 页面标题 |
| `--parent-h2` | 19 / 1.40 | 分节标题（"今晚可以聊"等） |
| `--parent-body` | 15 / 1.65 | 正文 |
| `--parent-caption` | 13 / 1.60 | 辅助说明、观察要点 |
| `--parent-meta` | 12 / 1.50 | 元信息、时间戳 |

**字重**：仅用 3 档 —— 400（正文）/ 700（强调）/ 800（标题）。不用 300（细体在低端安卓上发虚）。

## 1.10 动效规范

| 场景 | 时长 | 缓动 | 说明 |
| --- | --- | --- | --- |
| 帧/步骤切换 | 240ms | `cubic-bezier(.2,.8,.2,1)` | |
| 面/页面转场 | 240ms | 同上 | **不超过 600ms** |
| 星币流动 | 620ms，逐枚延迟 35ms | ease-out | 数量必须与教学数字一致 |
| 演示自动播放 | 每帧停留 3200ms | — | 足够孩子看清 |
| 按钮按下 | 120ms | ease-out | `scale(.97)` |
| 角色待机 | 3000ms 循环 | ease-in-out | 位移 ≤ 4px |
| 星星获得 | 400ms | 轻微上浮 + 淡出 | 不放大、不弹跳 |

**禁止**：闪烁、抖动、连续循环吸引注意、视差滚动、超过 600ms 的转场。
**降级**：系统 `prefers-reduced-motion` 优先于页面设置；开启后关闭所有非必要动效，保留状态切换的即时反馈。

## 1.11 声音规范

| 类型 | 规范 |
| --- | --- |
| 语音来源 | 浏览器 Web Speech API（**不调用付费配音 API，不使用麦克风**） |
| 默认语速 | 0.95×；可选 0.8× / 1.0× |
| 停顿 | 疑问句后 650ms（给思考时间）；普通句 260ms |
| 音高 | 疑问句 1.07；团团额外 +0.05（区分角色） |
| 数字朗读 | 数学符号转口语（`−` → "减"）；**金额与正负关系不可改写** |
| 答对音效 | C5–E5–G5 三音上行（523.25/659.25/783.99Hz），总长 ≤ 400ms，峰值 ≤ −12dBFS |
| 答错音效 | **无**。不播放任何音效 |
| 中断 | 返回地图、切步骤、暂停、切后台 → 立即取消播放 |
| 降级 | 无中文语音 → 保留完整文字 + 无声演示，**不阻断流程** |
| 家长端标注 | 必须写明"AI 生成配音" |

**禁止音效**：金币哗啦声、抽奖/开箱音、胜利号角、倒计时滴答、失败嗡嗡声。

## 1.12 文案语气规范（Tone of Voice）

### 五条原则

1. **第二人称**："你想买什么？" 不是 "请选择"
2. **短句**：单句 ≤ 20 字；不用被动句、不用双重否定
3. **不评判人格**：说行为，不说"你很聪明""你不够耐心"
4. **不制造焦虑**：不出现"落后""还没掌握""别人已经……"
5. **不用专业术语**：说"赚到的钱"不说"毛利"，说"还剩多少"不说"余额"

### 正反例对照表（开发时必须逐条对照）

| 场景 | ❌ 不要这样写 | ✅ 要这样写 |
| --- | --- | --- |
| 开场 | 欢迎使用本产品，请创建您的账号 | 嗨，我是小芽！你叫什么？ |
| 跳过选项 | 跳过此步骤 | 先不取名字，直接开始 |
| 提问 | 请选择正确答案 | 你想买什么？ |
| 答对 | 回答正确！+10 分 | 你先看了自己有多少钱，这个办法真好。 |
| 答错 | 回答错误，请重新选择 | 没关系，我们一起看看。再数一次，好吗？ |
| 超预算 | 余额不足，交易失败 | 咦，还差 1 枚。要换一个吗？ |
| 提示 | 点击查看提示（消耗提示次数） | 需要我陪你一起看看吗？ |
| 未解锁 | 该内容需开通会员后查看 | 这一段我还没学会呢。要不要去问问爸爸妈妈？ |
| 节结束 | 本节已完成，点击继续 | 今天发现了不少呢。去跟爸爸妈妈说说看？ |
| 家长空状态 | 暂无数据 | 怎么开始？先让孩子玩第一节，只要 12 分钟 |
| 家长结论 | 孩子的财商得分 82，超过 70% 同龄人 | 他今天学会了先看自己有多少钱，再决定买什么 |

## P-01 · 开场 · 小芽欢迎

**目的**：3 秒内让孩子进入状态，且**不制造任何填表负担**。

**布局**（自上而下）

```
┌──────────────────────────────┐
│         [ 小芽 · 欢迎表情 ]      │   ← 宽 140px，居中
│                              │
│  嗨，我是小芽！                 │   ← --kid-display
│  你叫什么？                     │
│                              │
│  ┌────────────────────────┐  │
│  │  在这里输入名字（可留空）   │  │   ← 输入框，高 56px
│  └────────────────────────┘  │
│                              │
│  [   开始吧   ]  ← 主按钮      │   ← 高 56px，--lime 底
│      先不取名字，直接开始        │   ← 文字链接，--muted 16px
│                              │
│  🔒 名字只留在这台设备上         │   ← 13px --muted
└──────────────────────────────┘
```

**元素规格**

| 元素 | 规格 |
| --- | --- |
| 角色 | `sunny-expressions.png` 第 1 格（欢迎），宽 140px |
| 标题 | `--kid-display` 32px，字重 800 |
| 输入框 | 高 56px，圆角 `--radius-md`，描边 `--border-strong`，字号 18px，maxlength 12 |
| 主按钮 | 高 56px，`--lime` 底 + `--ink` 文字，圆角 `--radius-md`，按下 `scale(.97)` |
| 跳过 | 文字按钮，16px，`--muted`，点击后昵称默认取"小朋友" |
| 隐私提示 | 13px，`--muted`，**必须可见**，不可折叠 |

**状态与规则**

- 昵称**可留空**，留空后所有文案用"你"，不出现占位名
- **不做**邮箱、年龄、年级、性别、头像上传
- 昵称仅存本机 localStorage，**不上传**
- 已存在昵称时**不再显示**本页，直接进入 P-02
- 输入内容中的 emoji、特殊符号允许保留，但渲染时限制为 12 字符

## P-04V · 节前趣味视频卡（第 0 步内）

**目的**：先用 60–120 秒把孩子拉进本节情境，再由孩子**主动**进入故事。

> 完整接口契约、降级链、制作规格与验收见 **`docs/VIDEO-MODULE.md`**。本节只给页面级规格。

**为什么是「视频 + 小游戏」而不是二选一**

| | 趣味视频 | 小游戏（现有练习） |
| --- | --- | --- |
| 负责 | **想看下去**：给动机、给画面 | **真的会做**：给决策、给后果 |
| 时长 | 60–120 秒 | 3–6 分钟 |

缺了视频，进门门槛高；缺了小游戏，看完就忘、家长判断不了「会没会」。**所以视频只能在每节开头，一节最多 1 段。**

**布局**

```
┌──────────────────────────────┐
│ ← 回地图      第 1 步 / 共 5 步  │
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │        [ ▶ ]             │ │  ← 16:9 画面区
│ │   先看一小段，再动手          │ │
│ │  看完就可以自己试一试。        │ │
│ │      [ 看视频 ]  约 1 分钟    │ │
│ │  AI 生成 · 已人工审核         │ │  ← 角标（条件显示）
│ └──────────────────────────┘ │
│  [ 先不看，直接开始 → ]         │  ← 出口，与主按钮同级可见
│  ▸ 看文字版                   │  ← 无障碍兜底
├──────────────────────────────┤
│  [   接着看故事 →   ]          │  ← 有片时文案自动变化
└──────────────────────────────┘
```

**元素规格**

| 元素 | 规格 |
| --- | --- |
| 卡片 | 白底，描边 `--line` 2px，圆角 `--radius-lg` |
| 画面区 | 16:9 固定比例，圆角 `--radius-md`，底色 `--deep`，`object-fit: contain` |
| 主按钮「看视频」 | 高 56px，胶囊形，`--lime` 底 + `--ink` 字，18px / 800 |
| 出口「先不看，直接开始 →」 | 高 52px，描边次要按钮 —— **不做次级弱化，与主按钮同级可见** |
| 时长提示 | 13px，「约 1 分钟」。**不显示精确秒数、不显示进度百分比** |
| 角标 | 12px 胶囊；AI 生成 `--yellow` 底，评审占位 `--purple` 底 |

**硬约束**

- ✅ **永不自动播放**、**永不自动跳步**（播完必须孩子自己点）
- ✅ **永不倒计时**，不显示缓冲百分比
- ✅ 跳过**不丢任何东西**：经验、星星、徽章照发
- ✅ 无片 / 坏片 / 离线 → 卡片不出现或降级为文字版，**流程一律可继续**
- ❌ 禁止红色错误态（用 `--coral` / `--muted`）
- ❌ 不记录观看时长（只记「看过 / 跳过」布尔值）

**空态与异常**

| 情形 | 表现 |
| --- | --- |
| 该节未配片 | **卡片不渲染**，页面与配片前完全一致 |
| 视频加载/解码失败 | 提示「这段片子这次没能播放。文字版和后面的练习都还在」，自动展开文字版 |
| 无字幕 / 无中文语音 | 视频照常播，「看文字版」始终可用 |
| 评审想确认位置 | 地址加 `?videoPreview=1` 显示占位（**孩子手里不可见**） |

**三条铁律**

1. **不给分数**。不出现"财商分""超过 70% 同龄人"
2. **不评价人格**。不出现"他很聪明""他不够耐心"
3. **不制造焦虑**。不出现"已经落后""还没掌握"

**话术生成规则**：每节课程数据中预置 `parent.talk[3]`（肯定 / 提问 / 生活延伸），**由编辑撰写**，不是 AI 实时生成。原因是质量可控，且避免把儿童数据发给第三方。
