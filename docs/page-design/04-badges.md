# 04 · 成就页

**文件**：`index.html` → `#badges-view`（`data-game-view="badges"`）
**样式**：`styles.css` → `.simple-view` / `.page-heading` / `.badge-grid`

---

## 1. 页面目标

给家长和孩子一份**诚实的学习记录**，而不是一份成绩单。

这一页的产品立场最重：

- 徽章代表「我已经练习过这个能力」，**不代表**真实投资水平 —— 文案里写死了这句话。
- 不给「财商分」，不评价人格，不排名，不与他人比较。
- 星星记录练习次数，**不是钱**，不能兑换。

## 2. 区块顺序

| # | 区块 | 内容 |
|---|------|------|
| 1 | 页面标题 `.page-heading` | eyebrow「学习记录」+ `h1`「我的成就徽章」+ 免责说明 |
| 2 | 星星卡（JS 动态插入到首位） | `★ N 颗学习星星` + 说明「每次完成一道练习获得一颗，复习也算。星星不是钱，也不代表投资能力。」 |
| 3 | 六张课程徽章卡（JS 由 `MoneyLessons.lessons` 生成） | 图标 + 课程标题 + 状态文案 |

**注意**：HTML 里静态写着 4 张徽章卡（利润小侦探 / 聪明采购员 / 负责小店长 / 风险观察员），但 `renderBadges()` 会用 **7 张**（1 张星星卡 + 6 张课程卡）整体替换 `.badge-grid` 的 `innerHTML`。因此静态的那 4 张只是首屏闪烁前的占位，**实际不展示** —— 属于可以清理的冗余标记（见 §6）。

## 3. 徽章卡

```
┌──────────────┐
│      🪙      │  52px 图标
│  我的钱有多少？│
│  我已经练习过  │  14px muted
└──────────────┘
```

| 状态 | 卡片表现 |
|------|---------|
| 已获得 | 浅绿底 `#f0fbdc` + 描边加粗 3px + `--e2` 硬边，全彩 |
| 未获得 | 灰阶 `filter: grayscale(1)` + `opacity: .45`，文案「一步一步来」 |

**栅格**：`repeat(4, 1fr)` / ≤900px 两列 / ≤640px 两列（`gap` 收到 8px）。卡最小高度 220px（≤640px 175px）。

**未获得卡的措辞**：用「一步一步来」，不用「未解锁」「未完成 0%」—— 灰阶已经表达了状态，文案不追加压力。

## 4. 排版检查结论

| # | 项 | 结论 |
|---|----|------|
| 1 | 卡片内已获/未获的对比 | 靠 `grayscale + opacity` + 描边粗细，不靠颜色，色盲可辨 ✅ |
| 2 | 星星卡与课程卡尺寸一致 | 星星卡也是普通 `article`，视觉权重与课程卡相同 —— 但它内容更少（一行大字），会显得空 ⚠️ 建议给它 `grid-column: span 1` 之外的强调，或改为顶部横条 |
| 3 | `--e2` 硬边与相邻卡的间距 | 硬边向右下偏移 6px 且不占布局高度，`gap: 14px` 足够；≤640px `gap: 8px` 时硬边会贴到下一张卡 ⚠️ 建议窄屏 gap 提到 12px |
| 4 | 与学习页的对齐轴 | 本页是卡片栅格，不与 720px 中轴对齐（合理），但 `.simple-view` 的 `width:min(1120px)` 与首页 `game-main` 通栏不一致 ⚠️ |
| 5 | 空态 | 有 1 张星星卡 + 6 张灰卡，**不存在空白页**；星星数为 0 时显示「★ 0 颗学习星星」，读起来像「你还没有」，与实际 0 次练习相符，可接受 |

## 5. 验收清单

- [ ] 未开始学习时：星星 0 颗、6 张灰度课程卡，文案为「一步一步来」。
- [ ] 完成第 1 课后：第 1 张卡变浅绿 + 描边加粗，其余仍灰。
- [ ] 答对一次练习后：星星卡数字 +1（**只有首次答对才 +1**，同一题重复答对不叠加）。
- [ ] 卡片上没有任何百分比、分数、排名、时间。
- [ ] ≤640px 两列布局不出现横向滚动条。
- [ ] 全灰状态下卡片文字仍可读（`opacity:.45` 下 14px 灰字对比度需实测 ≥3:1）。

## 6. 待确认 / 未完成

1. `index.html` 里静态的 4 张徽章卡是死代码（会被 JS 覆盖），建议删除。
2. 是否给「复习也算星星」加一个上限或去重（现状是每次答对都 +1，复习刷星星可能变成隐形 KPI，与「时长/次数不是 KPI」的立场有摩擦）。
3. 是否需要一个「本机累计学习约 N 分钟」的展示（当前这句只出现在家长中心 `#parent-progress`，刻意不放成就页）。
