# 01 · 首次进入页

**文件**：`index.html` → `#start-screen`
**样式**：`styles.css` → `.start-screen` / `.start-hero` / `.start-cast` / `.start-button` / `.start-note`

---

## 1. 页面目标

让第一次打开产品的孩子**在两秒内知道该点哪里**。

这个页面不是落地页、不是营销页、不是家长说明页。它是一个「门」：只有一个把手。

## 2. 谁在用

| 角色 | 诉求 |
|------|------|
| 孩子（8–12 岁） | 我不想读表格、不想选东西、不想勾同意框。我只想开始玩。 |
| 家长（在旁边） | 我要一眼看到：数据存哪、花不花钱、是不是真的投资建议。 |

两个诉求都要满足，但**主次分明**：孩子看到的是按钮，家长看到的是按钮下面那行小字。

## 3. 显示条件

```
state.started === false   →  显示本页
state.started === true    →  本页隐藏，直接落在经营地图首页（见 02）
```

`state` 来自 `localStorage["future-life-skills-money-game-v1"]`。

> **术语澄清（需确认）**：本产品**没有账号体系**，也没有登录接口（纯静态前端、数据仅存本机）。
> 需求里的「已经登录过的用户」在本项目中实现为「本机已有存档的用户」＝ 回访用户；
> 「登录页面」实现为「登录后的主页面」，即经营地图首页。
> 如果原意是要一个**真实的账号登录页**，需要先推翻「暂不涉及后端」这条既定边界。

## 4. 区块顺序（自上而下，一屏之内）

| # | 区块 | 内容 | 是否可省 |
|---|------|------|---------|
| 1 | 品牌条 `.start-header` | 智行未来学院 logo + 语言切换（中文 / EN） | 否 |
| 2 | 角色 `.start-cast` | 小芽（116px）+ 团团（84px）并排 | 否（唯一的情感锚点） |
| 3 | 大标题 `h1` | 「欢迎来到 **财商经营岛**」（岛屿名用 coral 色） | 否 |
| 4 | 一句话 `start-lede` | 「10 枚星币，先买什么？跟小芽一起，从第一课开始。」 | 否 |
| 5 | **唯一按钮** `#start-learning` | 「开始学习 →」 | 否 |
| 6 | 家长须知 `start-note` | 一行小字，14px / `--muted` | 否 |

**刻意不在这一页出现的东西**（改版时从这里移走的）：

| 移除项 | 去处 | 原因 |
|--------|------|------|
| 经营场景选择（奶茶 / 美甲） | 家长中心 | 孩子无法判断，且第一课不区分场景；默认 `bubble-tea` |
| 游戏昵称输入 | 家长中心 | 选填字段，在门口出现就是阻碍 |
| 「我是家长或监护人」勾选框 | 压缩成 `start-note` 一句话 | 合规信息保留，但不再要求孩子做一个法律动作 |
| 两张样板课入口卡（思考站 / 零花钱小镇） | 经营地图首页 | 首次进入应当只有一个入口；回访用户在地图页仍可见 |
| 学习循环图标条（学习→挑战→经营→解锁） | 删除 | 纯装饰，与「开始学习」抢注意力 |
| 岛屿预览（LEVEL 1 / MY WISH） | 删除 | 展示的是尚未解锁的内容，提前制造「我还没有」的焦虑 |

## 5. 排版规范

| 项 | 值 |
|----|-----|
| 容器 | `min(640px, 100% - 40px)`，`margin: 0 auto`，`text-align: center` |
| 垂直居中 | `display:grid; align-content:center; min-height: calc(100dvh - 100px)` |
| 区块间距 | `gap: var(--sp-3)`（16px） |
| 大标题 | `clamp(44px, 9vw, 76px)`，字重 800，字距 -0.035em，行高 1.06 |
| 说明行 | `clamp(17px, 2.4vw, 21px)`，行高 1.7 |
| 主按钮 | `min-height: 76px`（≤640px 时 68px + 通栏），胶囊形，字号 `clamp(23px, 3.4vw, 30px)`，字重 900 |
| 按钮配色 | 底 `--lime` / 字 `--ink`（10.07:1 AAA）/ 描边 `--bw` ink / 底边 `0 7px 0 --btn-edge` |
| 家长须知 | `--fs-sm`(14px)，`--muted`，`max-width: 46ch`，行高 1.7 |
| 背景 | 纸底 + 右上角一个 ink 描边空心圆 + 34px 网格线 + 两个角部色斑 |

**移动端（≤640px）**：`dvh` 兜住地址栏收起/展开（避免 `100vh` 跳屏）；角色缩小到 92px / 68px；按钮转为通栏。

## 6. 交互

| 动作 | 结果 |
|------|------|
| 点击「开始学习」 | `state.scenario = "bubble-tea"`（若为空）→ `state.started = true` → 立即 `openMission("lesson-1")` → 滚动到顶部 |
| 切换语言 | `setLanguage()` 重绘全站文案；`html[lang]` 同步 |
| 键盘 | Tab 顺序：跳到主要内容 → 语言切换 → 开始学习；按钮有 `:focus-visible` 3px coral 焦点环 |

**没有任何二次确认**：不弹窗、不问昵称、不问场景。孩子点一下就在第一课里了。

## 7. 状态清单

| 状态 | 表现 |
|------|------|
| 首次进入 | 正常显示 |
| 已开始过 | `hidden`，页面渲染为经营地图首页 |
| 家长中心「清除本机进度」后 | 存档被删 → 刷新 → 回到本页（预期行为，不是 bug） |
| JS 未加载 | 按钮无响应；`<noscript>` 提示仅存在于 `thinking.html`，本页**缺失**（见 §9） |
| 英文模式 | 按钮文案 / 标题 / 须知全部切换为英文 |

## 8. 验收清单

- [ ] 首次打开（清空 localStorage）只看到 **一个** 按钮，且它是页面上最大的元素。
- [ ] 点击「开始学习」后**直接**进入第 1 课第 1 步「故事时间」，中途没有任何弹窗或表单。
- [ ] 返回地图（学习页左上角「← 返回经营地图」）后**不会**再回到本页，而是落在经营地图首页。
- [ ] 按钮按下时有物理下沉（整体下沉 7px、底边收为 0），不是颜色变化。
- [ ] 375px 宽度下：标题不溢出、按钮通栏、须知文字不截断。
- [ ] 键盘 Tab 到按钮时有可见焦点环。
- [ ] 家长须知文案包含三个信息点：本机保存 / 虚拟货币 / 非投资建议。
