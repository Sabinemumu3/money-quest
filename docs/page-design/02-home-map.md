# 02 · 经营地图首页（回访落地页）

**文件**：`index.html` → `.game-app` > `#home-view`
**样式**：`styles.css` → `.game-header` / `.game-sidebar` / `.shop-hero` / `.mission-map-section` / `.coming-worlds`

---

## 1. 页面目标

回访用户（本机已有存档）打开产品后**直接落在这里**。它要同时回答三个问题：

1. 我上次学到哪了？→ 章节卡的「接着上次学」按钮
2. 我接下来能学什么？→ 六步学习路径 + 选学拓展
3. 我的店长身份是什么？→ 店头插画 + 店铺名 + 昵称

**它不是**导航目录：侧栏负责导航，首页负责「今天学哪一节」。

## 2. 布局骨架

```
┌─────────────── game-header（fixed，75px）────────────────────┐
│ [☰ 移动端] 品牌   👣3/6  ⏱12  ⭐LV.2        [中|EN]          │
├──────── 260px ────────┬──────────────────────────────────────┤
│ game-sidebar（fixed） │ game-main                            │
│  ├ 玩家卡（头像/昵称）│  home-view                           │
│  ├ 导航 4 项          │   ├ 样板课入口卡 ×2                  │
│  ├ XP 进度卡          │   ├ shop-hero（店头大图 + 目标 + 状态）│
│  └ 关闭菜单(移动)     │   ├ mission-map-section（学习路径）   │
│                       │   └ coming-worlds（深底，后续场景）  │
└───────────────────────┴──────────────────────────────────────┘
```

| 区块 | 内容 | 备注 |
|------|------|------|
| 顶栏 `.game-header` | 品牌 / 三项统计（课程完成数 `n/6`、本次分钟、等级） | 时间**不作为** KPI，只显示「本次用了多久」 |
| 侧栏 `.game-sidebar` | 玩家卡 + 4 项导航 + XP 进度 | 市场实验室默认 `disabled`，学完六课解锁 |
| 样板课入口卡 ×2 | 零花钱小镇 / 小芽思考站 | 外链到独立 HTML，不走存档 |
| `.shop-hero` | 店头插画 +「星光奶茶铺」+ 今日目标 + 两项状态 | 随场景（奶茶 / 美甲）变化 |
| `.mission-map-section` | 章节卡栅格（6 节 + 1 拓展）+ 学习提示 | **首页的主体** |
| `.coming-worlds` | 深底区块，3 张「后续场景」预告卡 | 纯预告，不可点 |

## 3. 章节卡（首页最重要的组件）

每张卡自上而下：

```
01                          [可开始 / ✓已完成 / 🔒]
🪙
钱的第一课
先认识钱的流入、流出和剩余。
故事 · 示范 · 陪练 · 自己试
+30 XP  +20 🪙
[ 陪小芽开始 → ]
```

| 状态 | 卡片表现 | 按钮 |
|------|---------|------|
| 可开始 | 白底 + ink 2px 描边 + e2 硬边 | 「陪小芽开始 →」（主按钮样式） |
| 学到一半 | 同上 | 「接着上次学 →」 |
| 已完成 | 浅绿底（`#f0fbdc`）+ 描边加粗到 3px | 「再次查看」，按钮转 lime 底 |
| 未解锁 | `filter: saturate(.25); opacity: .66` | 禁用 + 「先学会前一课」 |
| 拓展（市场实验室） | 紫底 `#f1edff` | 未解锁时「先学完六节基础课」 |

**hover**：卡片上移 3px，硬边从 `--e2`(6px) 加粗到 `--e3`(9px)。**不是加模糊**。

**栅格**：`repeat(3, minmax(0,1fr))`，≤1100px 两列，≤650px 单列。

## 4. 排版检查结论

### 4.1 已实施（本次）

| 项 | 说明 |
|----|------|
| 章节卡与主按钮已随「形状与阴影统一」收敛 | 全部走 `--e1~--e4` / `--btn-drop` 硬边，无模糊投影 |
| 场景选择器与本机角色设置迁入家长中心 | 原首次进入页的表单删除后，这些控件在首页**不出现**，只在家长中心出现（见 05） |

### 4.2 建议但**未实施**（需要产品确认后动）

| # | 问题 | 现状 | 建议 |
|---|------|------|------|
| 1 | **首屏第一眼是两张「别的产品」卡片** | 样板课入口卡排在 `shop-hero` 之前，回访用户先看到的是外链，而不是自己的学习路径 | 把两张入口卡移到 `mission-map-section` 之后，或收成一行「样板课」文字链接 |
| 2 | `.shop-hero` 占据首屏约 410px | 店头插画 360×276px，展示的是「已拥有」的信息 | 压缩到 260px 以内的窄条：店铺名 + 今日目标 + 两项状态，插画降为装饰性背景元素 |
| 3 | 三项顶栏统计各写一遍标签 | `👣 3/6` / `⏱ 12` / `⭐ LV.2` 只有 `title` 提示含义，孩子读不懂图标 | 改为图标 + 单位（如 `3/6 节`），或收进侧栏 |

| 5 | 首页未套阅读中轴 | 通栏 + `clamp(35px,5vw,68px)` 内边距在超宽屏上会把章节卡撑得很空 | 给 `game-main` 加 `max-width: 1360px; margin: 0 auto`（侧栏宽度另计） |

## 5. 交互与状态

| 动作 | 结果 |
|------|------|
| 点击章节卡按钮 | `openMission(lessonId)` → 打开学习页浮层（`#mission-layer`），滚动锁定 |
| 点击市场实验室 | 已解锁则直接 `openMission("mission-4")`；未解锁则侧栏项禁用 |
| 点击样板课卡 | 跳转 `thinking.html` / `money-lab.html`（离开本页） |
| 汉堡菜单（≤900px） | 侧栏从 `left:-280px` 滑入，带 `--e3-x` 侧向硬边 |
| 学习完成返回 | `#learning-notice` 替换为「这一课学完了。起来伸伸懒腰…」，焦点回到刚完成的卡片 |
| 顶栏统计 | 「本次用时」只在有活动时累加（离开页面/60 秒无交互即停），**不用于解锁任何内容** |

## 6. 验收清单

- [ ] 有存档时打开产品，**直接**落在地图首页，不出现首次进入页。
- [ ] 六个章节卡的状态与 `state.completed` 一致：只有一个未完成且可点的卡片（线性解锁）。
- [ ] 未解锁卡片的按钮 `disabled`，读屏可读出「先学会前一课」。
- [ ] 浅色卡片 hover 时硬边加粗而不出现模糊投影。
- [ ] ≤900px 时侧栏收起为抽屉，顶栏出现汉堡按钮。
- [ ] ≤650px 时章节卡单列，手指可点满卡片的按钮（≥48px）。
- [ ] 切换语言后，卡片标题 / 目标 / 按钮 / 状态标签全部切换。
