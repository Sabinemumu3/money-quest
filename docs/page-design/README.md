## 1. 页面地图

```

               ├─ 学习页（lesson-1 ~ lesson-6，5 步引导式）
```

## 2. 全局排版规范

### 2.1 阅读中轴

| 场景 | 中轴宽度 | 说明 |
|------|---------|------|
| 学习页（视觉区 / 对白 / 题目 / 反馈 / 主按钮） | **760px** | 整个课程页收窄到 760px（`body.is-lesson .mission-content`）；它是「一次一件事」，不跟关卡页同宽。主按钮再收窄到 460px |
| 关卡页（采购 / 顾客 / 市场） | 1060px | 需要并排卡片，允许更宽 |
| 简单页（成就 / 家长中心） | 1120px | 卡片栅格 |
| 首页卡片区 | 100% 通栏 + `clamp(35px,5vw,68px)` 内边距 | 通栏是首页的视觉特征，不套中轴 |

**规则**：一屏之内只允许一条对齐轴。禁止出现「标题靠左、正文居中、按钮回到左边缘」三种对齐同时存在的页面。

### 2.2 字号阶梯（8 档，下限 12px）

| Token | 值 | 用途 |
|-------|-----|------|
| `--fs-xs` | 12px | 全大写角标、状态标签（不承载阅读内容） |
| `--fs-sm` | 14px | 辅助说明、表头、元信息 |
| `--fs-ui` | 16px | 界面默认：按钮、导航、表单、标签 |
| `--fs-body` | 18px | 阅读正文：课程段落、对白、题目 |
| `--fs-h3` | 22px | 卡片标题 |
| `--fs-h2` | 28px | 区块标题 |
| `--fs-h1` | 34px | 页面标题 |
| `--fs-display` | `clamp(44px,7vw,92px)` | 首次进入页大标题 |

**页面级标题例外**：`h1` / `h2` 在页面里用 `clamp()` 直接写流式值，不吃 `--fs-h1/h2`。`--fs-h1` / `--fs-h2` / `--fs-display` 目前仅在首次进入页生效 —— 这是已知的不一致，见 §4。

### 2.3 间距阶梯（5 档）

| Token | 值 | 用途 |
|-------|-----|------|
| `--sp-1` | 8px | 紧密：图标与其标签、并列小元素 |
| `--sp-2` | 12px | 行内组：按钮与按钮、脚注与其主体 |
| `--sp-3` | 16px | 段落：正文块之间 |
| `--sp-4` | 24px | 区块：卡片之间、标题与内容之间 |
| `--sp-5` | 32px | 页面级分区 |

**规则**：同一屏内相邻块的间距只用这五档，禁止再写 14/18/22 这类孤立数值。控件内部 padding 与装饰性位移不受此限。
当前落地范围：首次进入页 + 学习页已全量改用 `--sp-*`；其余页面仍混用旧数值（`待收敛`）。

### 2.4 形状系统（方向 A「硬边纸玩」）

两条正交规则，先分清各自管什么：

| 规则 | Token | 用在 | 行为 |
|------|-------|------|------|
| ① 底部硬边 = 可按压 | `--btn-drop` 4px / `--btn-drop-sm` 3px | **仅按钮** | 只向下偏移；按下时整体下沉、边缘收为 0 |
| ② 对角硬边 = 纸片层叠 | `--e1` 4px → `--e4` 12px | **卡片 / 面板 / 浮层** | 向右下偏移、**不带模糊**，随体量递增 |

- **全站不使用任何带模糊半径的投影**；再出现 blur 投影即为回归。
- 圆角 5 档 + 胶囊：`--radius-xs 6` / `sm 10` / `md 16` / `lg 22` / `xl 28` / `pill 999`。刻意不收敛：50%（圆形）与手绘不规则半径（岛屿、客户头像）。
- 描边 3 档：`--bw 2px`（所有完整框住的表面）/ `--bw-strong 3px`（装饰插画、浮层、已达成容器）/ `--bw-accent 4px`（左侧强调条）。
- 单边强调条换色必须用 `border-left-color`，**不要用 `border-color`** —— 后者会连改另外三边。

### 2.5 按钮分组（新增按钮照此归类）

| 组 | 高度 | 按压量 | 例子 |
|----|------|--------|------|
| 主交互控件 | ≥46px | `--btn-drop` 4px | 卡片式选项、成排操作、播放/跳过 |
| 工具栏与紧凑控件 | 40–48px | `--btn-drop-sm` 3px | 返回、暂停、语音控制、加减计数器 |
| 落地页主按钮 | 76px（移动端 68px） | 7px | 首次进入页「开始学习」——全站唯一 |

刻意不适用硬边：分段控件（`.language-switch`，边缘会把胶囊撑破）、深底侧栏导航（`.game-nav`）、破坏性操作（`.danger-button`，保持扁平 —— 不做成更想按的样子）、跳过导航链接（`.skip-link`）。

### 2.6 颜色

- 12 个色 token 全部定义在 `styles.css :root`：`--ink #173f37`（主色）/ `--deep #0d302a`（侧栏底）/ `--paper #fbfaf4`（纸底）/ `--cream` / `--white` / `--lime #d9fb8f`（强调）/ `--coral #ff8265` / `--blue` / `--purple` / `--yellow #ffd96c`（奖励）/ `--muted` / `--line`。
- **当前只有 `styles.css` 与 `video.css` 在 token 表内取色**；`dialogue.css`、`thinking.css`、`money-lab.css` 仍有大量硬编码色值。已知问题，见 §4。
- 对比度基准：`ink on lime` = 10.07:1（AAA）。新增配色不得低于 4.5:1。
- 数字一律 `font-variant-numeric: tabular-nums`：金额、星币、倒计时在任何一次重绘里都不许改变占位宽度。

### 2.7 断点

**目标规范（3 档）**：`≤640px`（手机）/ `641–900px`（平板竖屏/抽屉态）/ `>900px`（桌面）。

现状（<span>待收敛</span>）：

| 文件 | 现有断点 |
|------|---------|
| `styles.css` | 1120 / 1100 / 900 / 650 / 640 |
| `dialogue.css` | 651 / 650 |
| `video.css` | 640 |
| `thinking.css` | 760 |
| `money-lab.css` | 760 |

新写规则统一用 640 / 900 / 1200 三个值。

## 3. 跨页面的公共约定

| 约定 | 说明 |
|------|------|
| 语言切换 | `html[lang="en"]` + `.zh` / `.en` 双写，**每新增一句文案必须同时写中英** |
| 跳转链接 | 每页第一个可聚焦元素是 `.skip-link` |
| 焦点可见 | `outline: 3px solid var(--coral); outline-offset: 3px`，禁止 `outline: none` |
| 触控目标 | 儿童端主按钮 ≥52px，紧凑控件 ≥44px |
| 动效 | 全部受 `prefers-reduced-motion` 控制，并提供页内「减少动画」开关（学习页） |
| 存档 | 4 个独立 localStorage 命名空间，**新模块必须开新 key**，不得污染既有存档；版本号 `version !== 1` 即重置，改 schema 必须同步写迁移 |
| 数据边界 | 不收集儿童真实姓名 / 学校 / 地址 / 生日；不接入真实券商、行情、支付 |

## 4. 已知待收敛项（不在本次改动范围）

| # | 项 | 现状 | 影响 |
|---|----|------|------|
| ① | 颜色收敛 + `--on-*` 配对 token | 去重后约 170 个色值 / 12 个 token（≈14×）；浅底上的文字色靠硬编码 | 主题改色要全仓搜；深色底上的文字对比度无人守 |
| ② | 断点统一 | 5 个文件 5 套断点（见 §2.7） | 同一宽度下不同页面排版不一致 |
| ③ | 标题档 token | `--fs-h1/h2/h3/display` 已定义但页面标题改用 `clamp()` | token 表与实际用法脱节 |
| ④ | 构建断言 | 目前只校验资源白名单 | 硬编码 hex（token 表之外）、<14px 字号、blur 投影无 CI 拦截 |
| ⑤ | `sw.js` 缓存清单 | `CORE_FILES` 未覆盖 `thinking.html` / `money-lab.html` | 离线时两个样板课不可用 |
| ⑥ | 主按钮按压量 | `.primary-button` 写死 `5px`（hover 4px / active 5px），与 `--btn-drop 4px` 并存 | token 表少了一档「主按钮」；主按钮与卡片选项的按压深度差 1px，无据可依 |
