# 07 · 零花钱小镇

**文件**：`money-lab.html` + `money-lab.js` + `money-lab.css` + `thinking.css` + `dialogue.css`
**主题**：存 · 花 · 捐 —— 由孩子自己决定

---

## 1. 页面目标

用 20 枚模拟币体验三个决定：**存多少、花多少、捐多少**。钱在口袋之间移动，**不是收入**。

产品立场（写进页面文案，不可删）：

- 不设置固定的「正确比例」；**0 捐赠和不投资都允许**。
- 存款按虚构固定年利率 5% 演示，一年一次结息 —— 真实利率与条款须另行核实。
- 没有真实付款、真实捐赠、真实证券账户。
- 「不接真实银行 / 支付 / 慈善组织」这句话在页脚常驻。

## 3. 排版检查结论

| # | 项 | 结论 |
|---|----|------|
| 1 | 三色口袋底色 | 绿 / 黄 / 红（`#f5f9ec` / `#fff6e4` / `#fff0ed`）—— **红色用在「捐」这个中性动作上是个暗示性错误** ⚠️ 建议换成中性色（紫 `--purple` 或蓝 `--blue`），避免把捐赠读成「警告/支出」 |
| 2 | 加减计数器 | 44×44px 圆形按钮 + 中间 24px 加粗数字，`min-width:68px` 防跳动 ✅ 数字已启用 `tabular-nums` ✅ |
| 3 | 到边界即禁用 | `:disabled` 时连底边一起收掉（`box-shadow: 0 0 0`），视觉上不再像可点 ✅ |
| 4 | `.lab-quiz button` 纵向间距 | 选项上下各 5px 外边距 + 紧凑按压量 3px，避免硬边顶到下一项 ✅（这是刻意的例外，已在代码内注明） |
| 5 | 顶部信息密度 | `.thinking-title` 与 `.lab-nav` 之间只有默认间距，导航 5 项在窄屏换成两行 ⚠️ 建议导航用紧凑图标 + 文字，≤760px 保留两行但收窄 padding |
| 6 | 断点 | 只有 760px（与思考站同）⚠️ 见总览 §2.7 |
| 7 | 颜色 token | 与 `thinking.css` 同样大面积硬编码 ⚠️ `#f5f9ec` / `#fff6e4` / `#fff0ed` / `#fcfff6` / `#e8f0dc` / `#eaf3fe` 等应并入 token |
| 8 | 家长区在同一个页签条里 | 「家长」与「存/花/捐」并列在 `.lab-nav`，孩子会点进去 ⚠️ 页面已用 `.parent-note` 说明「没有身份验证，不能防止孩子自行点击」，属于**已披露的已知限制**，不是遗漏 |
| 9 | 数字展示 | `.lab-summary strong`、`.jar-counter output`、`.market-outcomes strong` 三处大数字，字号 20–24px 不等 ⚠️ 建议统一到 24px |
| 10 | 折叠区的教学依据 | 用 `<details>` 收起，默认不占首屏 ✅ 但外链 `target="_blank"` 需确认已加 `rel="noopener noreferrer"`（现有代码已加 ✅） |

## 4. 验收清单

- [ ] 初始 20 枚币，三个口袋相加恒等于 20（`.balance-equation` 实时核对）。
- [ ] 加减到 0 或到上限时按钮 `disabled` 且视觉上不再是可按的样子。
- [ ] 「花」页签买一件后显示「还剩 N 枚」或「还差 N 枚」，**不出现真实付款流程**。
- [ ] 家长录入实物后，孩子端显示「家长录入的实物 · 是否交付仍需当面确认」，而不是「已购买」。
- [ ] 待确认申请在家长确认前**不扣币**。
- [ ] 银行结息按 5% 虚构年利率、一年一次、四舍五入到 0.01。
- [ ] 页脚常驻「仅教学模拟 · 没有真实支付或捐款」。
- [ ] 弹窗用原生 `<dialog>`，Esc 可关，背景不可聚焦。
- [ ] 760px 以下单列。
- [ ] 清空主应用存档不会影响本页（独立命名空间 `future-money-town-v1`）。
