配色禁忌（硬约束）

❌ 纯红 / 正红儿童端禁止出现红色错误态，一律用 --coral 或 --muted
❌ 涨跌色彩语义任何形式的红绿涨跌配色
❌ 荧光 / 渐变紫粉不用霓虹色、不用渐变紫粉
❌ 仅靠颜色区分状态必须同时有图标或形状差异

3形状 · 描边 · 阴影

本产品视觉靠「实线描边 + 圆角 + 平涂色块」建立手绘绘本感——描边为主，阴影为辅。不用重投影、不用玻璃拟态、不用多层渐变。
