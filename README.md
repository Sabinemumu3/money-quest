# 财商经营岛 V1

这是第一版真实可玩的儿童财商与商业管理产品。经营主题不是职业规划，而是用于理解金钱概念的游戏情境。

## 运行

直接打开 `index.html` 可以体验主要功能。若要测试安装与离线能力，需要通过本地静态服务器或 HTTPS 打开，因为浏览器不会在 `file://` 页面注册 Service Worker。

## 已实现

- 奶茶店、美甲店两种经营情境。
- 六课：有限的钱、先买什么、收支与利润、按需进货、储蓄、应对变化。
- 每课包含故事、逐步示范、陪练、迁移挑战和生活小活动；可看提示、免费重试。
- 顺序解锁、经验值、等级、徽章和按步骤续学；复习不重复发通关经验。
- 原创吉祥物小芽；六课支持中文/英文设备朗读、语速调整、停止和静音。
- 分步教学动画演示星币流入流出、库存和储蓄；可手动切换、播放、暂停、重播和减少动画。
- 每次成功完成练习（包括复习）获得一颗学习星星、短提示音和具体解释；刷新、重复点击已完成题目不会再次奖励。星星不是练习货币。
- 六课之后解锁可选虚构市场实验室，不计入基础课完成度。
- 本机学习时长、暂停恢复、温和休息提醒；时长不参与解锁。
- 中文/英文界面、移动端布局和本地进度保存。
- PWA manifest 与离线缓存基础，便于后续 App 化。

## 语音与奖励测试说明

朗读使用浏览器提供的声音，自动选择优先匹配语言、自然声线标识，也可手动试听切换；不是专门录制的真人或情感配音。“小芽讲故事”采用口语化文案、短句、思考停顿和小幅语调变化，不能保证所有设备都获得自然听感。默认 0.95 倍语速，保留更慢和普通朗读。不同设备的声音、语言包和播放权限不同；没有合适声音时保留完整文字与无声演示。浏览器也可能提供网络语音，设置中已说明，本项目不调用付费配音 API，不使用麦克风，不把昵称发送给朗读引擎。提示音通过 Web Audio 在浏览器内合成，受设备音量和浏览器播放限制影响。

静音同时关闭朗读和答对音效；返回地图、切换课程步骤、暂停休息和切换到后台都会取消播放。系统“减少动态效果”优先于页面动画设置。

学习星星保存在原有本机进度中，与练习钱袋、市场实验币、课程经验分开。错题不扣星，不设置连胜、倒计时或随机奖励。固定每道练习成功 +1，复习也鼓励；已通过状态不重复结算。

## 2026-09-20 角色对话版

六课故事、19 段演示、12 道练习引导、提示、错题反馈、发现总结与生活迁移，均通过小芽和团团逐句呈现。市场实验室也采用角色对话。每次显示一小段，不逐字打字、不强制等待；可以点击接着聊，也可以用设备语音连续播放。对话结束后由孩子主动进入下一步，语音不会自动答题或跳课。

演示中的钱币移动与台词同步。小芽有欢迎、好奇、开心、安慰四种表情，角色轻微摆动遵守减少动态效果设置。保存既有存档、当前对话位置和答题反馈，刷新不会再次发星或播放音效。家长中心保留完整说明，不以减少儿童阅读为由隐藏教育和隐私边界。

本版没有调用付费配音 API，没有把待确认的配音试听接入课程。两个人物目前使用设备声线与轻微语调差异，不代表两套专门录制的角色配音。原 `sunny-mascot.png` 只保留为历史参考，不再用于界面。

本机回归脚本：`../outputs/money-quest-qa/check-dialogue.cjs`。验证内容包括完整六课正误回答、数学与库存、星星/音效、保存续学、暂停、38 个双语演示场景、市场风险对话、窄屏、静音与减少动画。

## 在另一台电脑运行

需要 Node.js（建议 20 或以上），不需要安装第三方运行依赖。

```sh
npm run build
node scripts/preview.mjs
```

浏览器打开 `http://127.0.0.1:4107/`。样板课在 `/thinking.html`，零花钱小镇在 `/money-lab.html`。页面记录保存在当前浏览器中，不会随 GitHub 上传。GitHub 保存源码，不代表网站自动部署；`.openai/hosting.json` 仅描述现有 Sites 发布项目，不含登录令牌。

## 零花钱小镇的边界

- 初始 20 枚虚拟币，自主分为存/花/捐，不强制捐赠、不规定比例。支持重新分配和模拟捐出。
- 存款演示使用虚构固定年利率 5%，每个模拟年结息一次，四舍五入至 0.01 枚，最多观察三年；不能据此推断现实收益。
- 市场采用独立的 100 实验点，比较三个预设情境。没有随机中奖、不以收益给分；保留现金、不投资也是选项。
- 家长可以输入愿意提供的实物及模拟价格。申请不扣币；本机确认后只扣虚拟余额。不连接付款、物流、库存、慈善或金融账户。此确认没有家长身份认证，不适用于真实支付或正式兑换。
- 新模块使用独立存储键 `future-money-town-v1`，不更改原六课与野餐样板课存档。只重置小镇时会清除其本机实物清单，操作前有确认。
