# 财商经营岛 V1

这是第一版真实可玩的儿童财商与商业管理产品。经营主题不是职业规划，而是用于理解金钱概念的游戏情境。

## 运行

直接打开 `index.html` 可以体验主要功能。若要测试安装与离线能力，需要通过本地静态服务器或 HTTPS 打开，因为浏览器不会在 `file://` 页面注册 Service Worker。

## 已实现

- 奶茶店、美甲店两种经营情境。
- 钱的流入与流出、预算采购、定价与现金流任务。
- 顺序解锁、经验值、等级、经营资金、声誉和徽章。
- 完成经营任务后解锁虚构市场实验室。
- 中文/英文界面、移动端布局和本地进度保存。
- PWA manifest 与离线缓存基础，便于后续 App 化。

## 已验证

- 奶茶店路径可完成四关：资金 152、声誉 65、经验 140、等级 3、四枚徽章。
- 美甲店路径可完成前三关，并正确解锁市场实验室。
- 市场组合从 100 实验币变化为 99，能够展示分散投资仍可能亏损。
- 中英文动态内容正常；390px 手机视口页面宽度为 390px，无横向溢出。

预览文件：`preview-complete-desktop.png`、`preview-market-desktop.png`、`preview-complete-mobile.png`。

## 文件

- `index.html`：界面、四个任务和家长中心。
- `styles.css`：品牌视觉、游戏组件与响应式布局。
- `app.js`：游戏状态、任务、经营与市场模拟。
- `manifest.webmanifest`、`sw.js`、`icon.svg`：可安装 Web App 基础。
- `PRODUCT_BLUEPRINT.md`：定位、教学阶梯、安全边界和验证指标。
